   CloudVault Record Index  -  B+ Tree indexed record search
   BLAST 01  |  B+ Tree x Cloud / Databases
==============================================================
Every stored cloud resource has a numeric record ID. A B+ tree
of order 4 (max 3 keys per node) maps each ID to its
metadata, so a lookup reads one node per level instead of
scanning every record.
